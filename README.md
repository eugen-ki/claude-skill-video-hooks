# Video-Hooks: die ersten Sekunden mit Claude Code

Ein Claude-Code-Skill, der Hooks für dein Video schreibt und bewertet, für Reels, TikTok, Shorts und YouTube. Die besten drei bekommst du als Paket aus Bild, gesprochenem Satz und Texteinblendung.

## Was du bekommst

- Hooks aus fünf Blickwinkeln.
- Die besten drei mit Bild, Satz und Texteinblendung.
- Eine Bewertung mit vier Prüfungen und eine klare Empfehlung.

## Installieren

1. Oben rechts auf **Code** und dann **Download ZIP** klicken. ZIP entpacken.
2. Im entpackten Ordner liegt der Ordner `video-hooks`. Kopiere genau diesen Ordner in deinen Skills-Ordner:
   - Windows: `C:\Users\<dein-name>\.claude\skills\`
   - Mac: `~/.claude/skills/`

   Gibt es den Ordner `skills` noch nicht, leg ihn an. Danach liegt die Datei unter `.claude/skills/video-hooks/SKILL.md`.
3. Claude Code neu starten.

## So benutzt du ihn

Tippe `/video-hooks` oder sag es einfach in deinen Worten, zum Beispiel:

> Ich brauche Hooks für ein Reel: wie ich mit KI meine Rechnungen in 5 Minuten schreibe.

## Tipp: zuerst dein Profil

Der Skill klingt nach dir, wenn du vorher einmal [mein-profil](https://github.com/eugen-ki/claude-skill-mein-profil) installierst und `/mein-profil` startest. Ohne Profil funktioniert er auch, er stellt dir dann ein paar kurze Fragen.

## Was du brauchst

- Nur [Claude Code](https://claude.com/claude-code).

## Gut zu wissen

- Der Skill erfindet keine Zahlen oder Ergebnisse. Was er nicht weiß, steht in `[eckigen Klammern]`. Füll diese Stellen vor dem Veröffentlichen mit echten Angaben.
- Das Ergebnis speichert er als Datei in dem Ordner, in dem du Claude Code gestartet hast.
